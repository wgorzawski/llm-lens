The problem

Building with LLMs means flying blind.

You ship prompts. You get outputs. But everything in between — what was sent, what happened, what it cost — is invisible.

No visibility

You see the final output. You don't see the exact prompt, the system message, or what the model actually received.

No history

Bugs in LLM behavior are hard to reproduce. Without a log, you're guessing what happened during that failed run.

No cost control

Token counts are buried in response objects. You find out how much you spent at the end of the month.

How it works

Zero-config setup.
Full visibility in under a minute.

Three steps from zero to complete LLM observability — no SDK changes, no infrastructure, no overhead.

01

Instrument your client

Wrap your existing OpenAI client once. No other changes needed — every subsequent call is automatically captured.

TypeScript 
import OpenAI from "openai";
import { instrumentOpenAI } from "@llm-lens/instrument";

const client = instrumentOpenAI(new OpenAI(), {
  apiUrl: "http://localhost:3001",
  apiKey: process.env.LLMLENS_API_KEY,
});
TypeScript 
// Nothing changes here
const response = await client.chat.completions.create({
  model: "gpt-4o",
  messages: [{
    role: "user",
    content: "Hello"
  }],
});
02

Call your API as usual

Every call is captured in the background — zero latency impact on your app. The instrumentation is fully transparent to your existing code.

03

Open LLM Lens

Every request and response, normalized and visualized. System prompts, tool calls, token usage — all in one place. No digging through logs.

Features

Everything you need to understand
what your model is doing.

From raw JSON to beautiful conversation threads — LLM Lens gives you the full picture.

Multi-provider support

OpenAI, Anthropic, and Vercel AI SDK — all normalized to the same unified format. Switch models without losing your history.

Chat-style visualization

Every trace rendered as a conversation thread — user, assistant, tool calls, system prompt. Exactly how the model sees it.

Tool call inspector

Collapsible blocks showing tool name, input JSON, and results. Debug complex agent flows without digging through raw logs.

Usage stats per call

Input tokens, output tokens, cache hits, and latency — right next to each trace. No math required.

Auto-instrumentation

@llm-lens/instrument patches your client in-place. Fire-and-forget delivery — if LLM Lens is unreachable, your app never notices.

Full raw JSON access

The original provider response is always one click away. No surprises — what you see is what the API returned.
